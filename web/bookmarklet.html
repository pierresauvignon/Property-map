Ajouter à Property Map

Un bouton à garder dans la barre de favoris. Sur une annonce SeLoger, Leboncoin ou Belles Demeures, un clic lit la page et ouvre la fiche pré-remplie.

Version 6. Un bookmarklet embarque son propre code : quand il change, il faut refaire glisser le bouton. Property Map te préviendra si ta version est en retard — inutile de vérifier de toi-même.

Installation

  1. Affiche la barre de favoris : ⌘⇧B (Chrome, Mac).
  2. Fais glisser ce bouton dessus :

Ajouter à Property Map

  1. Ouvre une annonce, puis clique le favori.
  2. Vérifie les champs, place le point si besoin, enregistre.

Ce qui est lu automatiquement

Prix, surface, nombre de pièces, toutes les photos (en pleine largeur, sans doublons), adresse et commune quand la page les expose, et le lien de l’annonce. Le reste se complète à la main.

Sur un bien déjà dans la liste

Si le lien correspond à un bien existant, Property Map le reconnaît et propose de le mettre à jour plutôt que d’en créer un double — c’est ainsi qu’on récupère les photos d’une annonce ajoutée à la main.

Le bouton lit uniquement la page ouverte, dans ton navigateur — c’est pour ça qu’il fonctionne là où un serveur se ferait bloquer. Si un site change sa mise en page, certains champs arriveront vides : la fiche s’ouvre quand même, il suffit de les taper.
